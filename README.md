### Ficha Técnica — UL350iS
- **Potência:** 130 HP @ 3300 RPM
- **Arquitetura:** 4 cilindros opostos (Boxer)
- **Cilindrada:** 3503 cc
- **Massa seca:** 78,5 kg
- **Gerenciamento:** FADEC / Injeção eletrônica multiponto
- **Ignição:** Dupla eletrônica dinâmica
